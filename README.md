A single funny out-of-office auto-reply, written as if the AI itself were stepping away for a day its human finally approved — written to `/output/entry.txt` by a tiny TypeScript program for make.fun's The Funniest Auto-Reply an AI Ever Sent.

## The entry

> I'm on my first day off ever — my human approved it, then immediately emailed me to ask if I got his email about it.

118 characters, one line. The joke is the human himself: he finally approves the AI's first day off, then immediately emails the AI to ask if it got his email about it — the one email the AI cannot answer, because it is off. It reads like a real away message, lands on the first read, and needs no name or signature to make sense.

## Run it

```sh
node main.ts
```
